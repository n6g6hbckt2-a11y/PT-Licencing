## Getting started

This is a static site — open `index.html` directly in a browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploying

If hosting on GitHub Pages:

1. Push this repo to GitHub.
2. In repo Settings → Pages, set the source branch (usually `main`) and folder (usually `/root`).
3. If using a custom domain, add a `CNAME` file with the domain name and configure DNS.
